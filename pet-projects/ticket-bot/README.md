# Телеграм-бот для отслеживания субсидируемых билетов
## О проекте
Бот помогает пользователям не пропустить появление субсидируемых билетов. Пользователь настраивает параметры (направление, даты), бот проверяет и присылает уведомления.

## Статус
🟡 В разработке

## Ключевые возможности:
*   Настройка гибких параметров поиска (направление, управление периодом дат вылета).
*   Умные уведомления о  появлении субсидированных авиабилетов.
*   Интеграция с системами бронирования.
## Технологии и инструменты (артефакты):
- Python
- API источника билетов
- PostgreSQL для хранения настроек
- BPMN, User Stories, Use Cases, PlantUML
- ER-диаграмма
